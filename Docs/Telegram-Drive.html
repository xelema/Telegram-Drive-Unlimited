Getting started

Three steps, then it is your workspace.

Telegram requires every third-party client to identify itself with an API ID and hash. Those credentials are entered once and kept on your device.

Create API credentials

Visit my.telegram.org, open API development tools, and create an application to receive your API ID and hash.

Sign in securely

Use Telegram’s QR device flow on desktop. Phone-code and cloud-password flows remain available when Telegram permits them.

Start with what you have

Saved Messages becomes the home location. Existing or newly created channels appear as additional folders.

Trust model

A local app, not another cloud account.

Telegram-Drive does not operate a file relay or hosted file database. Transfers happen between the app on your device and Telegram.

Local credentialsTelegram credentials, vault keys, and connection settings stay on the device unless you explicitly use encrypted settings sync.
Local services are opt-inREST and WebDAV are disabled by default, bind to loopback by default, and require capability credentials.
Encryption is explicitProtection is optional and recovery is your responsibility. Keep independent backups of important files and recovery material.

Questions

Before you install.

Where are my files stored?

In your own Telegram account. Saved Messages acts as the home location and channels act as folders. Telegram-Drive does not operate a separate file-storage service.

Is the storage unlimited?

No. Storage and file handling follow Telegram’s account, service, and per-file limits. Telegram-Drive currently limits a Telegram object to roughly 2 GB, with slightly less available for encrypted files because of envelope overhead.

Does the $5 license unlock features?

No. Every feature is available in the free version. The lifetime supporter license only removes supported desktop sponsor placements and helps fund development.

Do normal updates require reactivation?

No. A verified device keeps its secure entitlement through normal application updates. Keep the recovery code for reinstalls or another eligible device; the license supports up to three desktop devices.

Are WebDAV and the REST API public?

They are disabled by default and bind to loopback by default. REST uses an API key, while WebDAV uses a capability URL and starts in read-only mode. Network exposure remains under the user’s control.

Is Telegram-Drive affiliated with Telegram?

No. Telegram-Drive is an independent open-source project that uses Telegram’s client API. Review the source and documentation on GitHub.
